# Next empirical step and conditions for expansion

The next credible empirical test would compare the frozen v002 predictions
against independent, accuracy-qualified reference observations. No suitable
dataset is available locally. The user permanently prohibits contacting anyone;
the earlier unsent request was withdrawn. Do not send messages, approach a
custodian, or ask again about outreach. Any future reference data must become
legally available through public sources or be supplied locally without agent
contacting third parties. Until then, report the evidence limit explicitly.

Required observations: confirmed natural limestone/marble entrances; source and
method/date; horizontal/vertical datum where available; estimated positional
uncertainty; whether entrances belong to the same cave or survey cluster; and
permitted uses. Unknown inventory completeness and nonrandom exploration remain
limitations even with precise coordinates. The predeclared primary localization
analysis needs positional uncertainty ≤25 m and uses 5/10/25 m tolerances.

Do not train on the validation locations and then use them again as independent
validation. If labels later support supervised work, reserve geographic cave
clusters or independent regions for testing before model selection. Given the
current few clustered, unverified public records, a train/test split would be
misleading; no supervised model is fit.

If independently verified results demonstrate useful gain beyond geology-only
and simple surface baselines, select new study areas from carbonate geology and
data availability without consulting local cave inventories. Freeze regional
boundaries, scales, thresholds, candidate ranking and evaluation protocol before
validation. Apply the existing scripts in a separate data/output tree and retain
all components. A genuinely new geographic holdout provides evidence unavailable
from further tuning at Cave Ridge.

Non-invasive field verification would require current land-manager permission,
conservation/decontamination requirements and qualified survey arrangements.
No field trip, opening entry, excavation or disturbance is currently proposed.
Do not generate or promote new prospecting leads as validated findings until the
reference-data uncertainty and baseline comparison support that step.
